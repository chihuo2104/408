## 广义表

### 广义表的相关特性

- 数据元素有相对次序
- 长度为最外层包含元素个数
- 深度定义为所含括弧的重数，空表深度为1，原子的深度为0
- 广义表可以共享
- 可以是一个递归的表，广义表可以是自己的子表
- 任何一个非空广义表均可分为表头(a1)和表尾(a2,.....,an)两部分

### 广义表的存储结构

保留第一个元素，然后在第二层的时候将剩下元素用链表的方式来进行连接。

## 第七章 树和二叉树

### 树，树的定义

T = { D, R }，D 是包含 n 个节点的有穷集合(n >= 0)，当 n = 0 时为空树，否则关系 R 满足以下条件：

- 有且仅有一个节点 d0 属于 D，它对于关系 R 来说没有前驱节点，节点 d0 称作树的根节点
- 除节点 d0 外，D中的每个节点对于关系 R 来说都有且仅有一个前驱节点
- D 中每个节点对于关系 R 来说可以有零个或多个后继节点。

树石由 n 个节点组成的有限集合（记为 T），其中：

- 如果 n = 0，它是一棵空树，这是树的特例
- 如果 n > 0，这 n 个节点中存在（有仅存在）一个节点，那个节点无前驱，称为树节点

### 树的表示

1. 树形表示法

不方便存储，树的最基本的表示方式，比较直观

2. 文氏图表示法

使用集合（Venn图）体现

3. 凹入表示法

使用线段的伸缩来表示描述树结构

4. 括号表示法

可以参考广义表，根节点写在括号左边，其余节点写在括号中并用逗号间隔来描述树的结构

括号，树形表示法进行相互切换

### 树的基本术语

1. 节点的度和树的度

树中某个节点的子树的个数 ，树中个节点的度的最大值就是树的度，通常将度为 m 度树为 n 次树

2. 分支节点和叶节点

度不为 0 的节点称为非终端节点，又叫分支节点。度为 0 的节点称为终端节点或叶节点。

在分支节点中，每个节点的分支数就是该节点的度。（单分支节点 => 1, 双分支节点 => 2, 三分支节点 => 3, ...)

3. 路径和路径长度

对于任意两个节点 di 和 dj，若树中存在一个节点序列 di，di1，.....,din,dj，使得序列中除 di 外的任意节点都是其在序列中的前一个节点的后继，则称该节点序列为由 di 到 dj 的一条路径，用路径所通过的节点序列 (di, di1, ......, dj) 的长度为路径长度

4. 孩子节点、双亲节点和兄弟节点

每个节点的后继都称为该节点的孩子节点/子女节点，相应的，该节点被称作孩子节点的双亲节点/父母节点

具有统一双亲的孩子节点互为兄弟节点，可以把每个节点的子树都称作子孙节点。

类似于家谱。

5. 节点的层次和树的高度

书中的每个节点都处在一定的层次上，层次从树根开始定义，根节点为第一层，它的孩子节点为第二层，以此类推，一个节点所在的层次为其双亲节点所在的层次 +1

树中节点的最大层次称为树的高度（或树的深度）

6. 有序树和无序树

若树中各节点的子树是按照一定的次序从左向右安排的，且相对次序是不能随意变换的，则称为有序树，否则称为无序树。

7. 森林

n 个互不相交的树的集合

把 n 个树 加一个根节点连一起可把森林变成树，反之亦然。

### 树的性质

1. 节点数 = 所有节点的度数 + 1
2. 度为 m 度树中第 i 层上至多有 m^i-1 个节点
