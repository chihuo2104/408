### 栈的基本运算

- InitStack(&s) 初始化栈，构造一个空栈s
- DestroyStack(&s) 销毁栈
- StackEmpty(s) 判断栈是否为空
- Push(&s, e) 入栈
- Pop(&s, &e) 出栈
- GetTop(s, &e) 求栈顶元素

遍历 求长度和查找都没有，对于线性表来比的话。

### 栈的基本运算的顺序存储实现

假设栈的元素个数最大不超过正整数 MaxSize，所有的元素具有同一数据类型 ElemType，则可用下列方式来定义栈类型 SqStack：

```c
typedef struct {
    ElemType data[MaxSize];
    int top; // 栈顶指针（实际上是一个下标，栈顶元素所在的位置）
} SqStack;
```

顺序存储就是把栈用数组进行表示了

顺序栈四要素：

- 栈空：`top = -1;`
- 栈满：`top = MaxSize - 1;`
- 进栈操作： `top++; Stack[top] = e;`
- 出栈操作： `e = Stack[top]; top--;`

### 实现

- 初始化栈 `InitStack(SqStack *&s)`

```c
void InitStack (SqStack *&s) {
    s = (SqStack *) malloc(sizeof(SqStack));
    s -> top = -1;
}
```

- 销毁栈 `DestroyStack(SqStack *&s)`

```c
void DestroyStack(SqStack *&s) {
    free(s);
}
```

- 判断栈是否为空 `StackEmpty(s)`

```c
bool StackEmpty(SqStack *s) {
    return s -> top == -1;
}
```

- 入栈 `Push(&s, e)`

```c
bool Push(SqStack *&s, ElemType e) {
    if (s -> top == MaxSize - 1) return false;
    s -> top++;
    s -> data[s -> top] = e;
    return true;
}
```

- 出栈 `Pop(SqStack *&s, ElemType &e)`

```c
bool Pop(SqStack *&s, ElemType &e) {
    if (s -> top == -1) return false;
    e = s -> data [s -> top];
    s -> top--;
    return true;
}
```

- 取栈顶元素 `GetTop(s)`

```c
bool GetTop(SqStack *s, ElemType &e) {
    if (s -> top == -1) return false;
    e = s -> data[s -> top];
    return true;
}
```
