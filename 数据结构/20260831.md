### 什么是数据结构？数据结构的定义？

数据：所有能被输入到计算机中且能被计算机处理的符号的 **集合**。

数据元素：是 **数据集合** 中的一个个体，是数据的基本单位。

e.g. 2班 为一个学生数据对象，其中的“张三”是一个数据元素。

数据结构：数据以及数据元素之间的相互联系，亦可看作是相互之间存在特定关系的数据元素的集合。

### 数据结构包含着什么？

逻辑结构：数据元素之间的逻辑关系

存储结构/物理结构： 数据元素及其关系（数据结构）在计算机存储器中的存储方式

运算：在数据上施加的操作

全书围绕着这三个部分进行展开。

### for example

学生表，存放着一些学生的信息，存放的信息包括学号、姓名、班级和性别。此学生表就是一种逻辑结构的表现方式（一个二维的 table，每个学生占据单独一行，如下表：）

| 学号 | 姓名 | 性别 | 班级 |
|----|-----|-----|------|
|1| 张三 | 男 | 1班 |
|7| 金郑恩 | 男 | 1班 |
|5| 李四 | 男 | 1班 |
|3| 威廉 | 男 | 1班 |

为了表示这张表中学生的关系（如前/后的顺序），我们用上表表示的话就会觉得存在数据冗余，所以可以使用以下序偶来表示线性关系[^2]：

```text
<1,7>,<7,5>,<5,3>
```

[^2]: 其中尖括号“<ai,ai+1>”表示元素 ai 和 ai+1 之间是相邻的，即 ai 在 ai+1 之前，ai+1 在 ai 之后。

或者我们可以使用更加清楚的方式来表示：

```text
1 -> 7 -> 5 -> 3
```

这不就是 C语言 课程中的链表表示吗？

### 存储结构

```text
       映射
逻辑结构 -> 存储结构
```

比如说，结构体就是一种比较经典的实现。（另外还有一种是链表表示）

比如说上文中可以定义为一个结构体

```c
struct student {
  int stuNo;
  char name[10];
  bool sex;
  char class[10];
}
```

并创建一个数组 `student Stu[100]`

或者说创建一个链表：

```c
struct student {
  int stuNo;
  char name[10];
  bool sex;
  char class[10];
  student *next;
  student *prev;
}
```

并创建一个 `head` 指针开始使用。

顺序存储结构：各元素在内存中顺序存放，即第 i 个学生对应的元素 stu[i] 存放在第 i+1 个学生对应的元素 stu[i+1] 之前，stu[i+1] 正好在 stu[i] 之后。结构体就是一个经典的顺序存储结构。

链式存储结构：各元素在内存中随机存放，但是会用头指针和尾指针进行导航，通过指针进行连接。链表就是一个经典的链式存储结构。

> 一个问题：为什么会有这两种存储结构在一起呢？

Pros & Cons

| 名称 | Pros | Cons |
|------|-------|-------|
|顺序存储结构|连续可读，实现简单|在头与中间插入和删除效率低|
|链式存储结构|在头与中间插入和删除效率高|实现较难，连续不可读，无法使用索引获取|

### 结论

- 同一逻辑结构可以对应多种存储结构
- 同样的运算，在不同的存储结构中，其实现过程是不同的

大致的 SOP：

分析 -> 选择合适存储结构(简单高效的算法) -> 实现

### 通用的逻辑结构的表示方法

通常使用 *二元组* 来更确切的描述一种数据结构。

`B=(D,R)`

D: Data(数据), R:Relation(关系)

其中，B 是一种数据结构，它由数据元素的集合D和D上二元关系的集合R所组成。

其中：

```D = {di | i<= i <= n, n >= 0}```

每个关系用 **序偶** 表示。

序偶 `<x,y>` => x 为第一元素，y 为第二元素。

x 为 y 的前驱元素，y 为 x 的后继元素。

若某节点无前驱元素，则称该节点为 **开始元素**。若某节点无后继元素，则称该节点为 **终端元素**。

`<x,y>` 表示 **有向关系** ，`(x,y)` 表示 **无向关系**。

### for example

如一个矩阵（可以视为二维数组），那该如何表示这种关系呢？

*需要表示行关系和列关系，`R = {r1, r2}`，r1 为行，r2 为列。*

### 逻辑结构

1. 线性结构

节点之间的关系：一对一

开始节点和终端节点都是唯一的。除了开始节点和终端节点意外，其余节点都有且仅有一个前去节点，有且仅有一个后驱节点。线性表就是一种典型的线性结构。

2. 树形结构

节点之间的关系：一对多

特点：开始节点唯一，终端节点不唯一。除终端节点以外，每个节点有一个或多个后续节点；除开始节点外，每个节点有且仅有一个前驱节点。
二叉树就是典型的树形结构。

3. 图形结构

节点之间的关系：多对多

特点：没有开始节点和终端节点，所有节点都可能有多个前驱节点和多个后继节点。地图（简化版本）的最短路径处理就是典型的图形结构。
