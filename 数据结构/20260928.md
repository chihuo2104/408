## 数组的存储结构

数组是用一片的连续空间进行存放的，定一个数组，系统就会分配一个连续的存储空间来存储（还有切片 slice 这种概念，可以进行思考和推广0

数组的大小一开始是给定的，数组中的元素一定是同类型的，使用下标来对数组的元素进行识别

数组是一种随机的存储结构，随机性体现在可以随机读取数组的随机的位置的元素。

一维数组是有存储空间存储地址的空间值可以获取的。

多维数组，以二维数组为例，实际上就是 “一位数组的数组”，可以把它看成一个矩阵。存放时（按行/按列）进行存放？

C/C++及绝大多数的高级编程语言使用的是按行为组序进行存储的。 R 是以列为组序进行存储的。

可以获得以下公式(以行为组序的)：

```
LOC(aij) = LOC(a11) + [(i - 1) * n + (j - 1)] * k
```

其中，n 为此二维数组的列数。以此可以推广至 n 维。

## 对称矩阵的压缩存储

若一个矩阵上三角和下三角元素 aij = aji，可以称为n阶对称矩阵

满足主对角线对称，在存储时仅需存储上下三角元素即可，将 n^2 个元素 化成了 n(n+1) / 2 个 元素的空间中。

时间一般来说是优先的，让位于空间
