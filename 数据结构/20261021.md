## 计算二叉树的结点个数

### 任务描述

假设二叉树采用二叉链存储结构，设计一个算法，计算给定二叉树的结点个数。

结点类型定义如下：

```c
typedef struct node 
{    
    ElemType data;            //数据元素
    struct node *lchild;    //指向左孩子结点
    struct node *rchild;    //指向右孩子结点
} BTNode;
```

### 解题思路

求解二叉树b的结点数目问题，可以转化为求解其左子树和右子树的结点数目问题，利用递归思想完成。递归模型f(b)如下：

```text
f(b) = 0 (若 b = NULL)
f(b) = f(b -> lchild) + f(b -> rchild) + 1 (others)
```

### 测试输入：

```
A(B(D(,G)),C(E,F))
```

### 预期输出：

```
b:A(B(D(,G)),C(E,F))
结点个数:7
```

### 提供代码

```c
#include "btree.cpp"
int Nodes(BTNode *b)
//此处填写代码,计算一棵给定二叉树的所有节点个数
{	





}
```

### 参考答案

```c
#include "btree.cpp"

int Nodes(BTNode *b)
// 计算一棵给定二叉树的所有结点个数
{
    if (b == NULL)
        return 0;
    else
        return Nodes(b->lchild) + Nodes(b->rchild) + 1;
}
```

int Level(BTNode *b, ElemType x, int h)
// 求二叉树中指定结点的层次，h初值为1
{
    int l;
    if (b == NULL)
        return 0;
    else if (b->data == x)

## 层次遍历

### 任务描述

编写二叉树的层次遍历算法。

二叉树采取二叉链存储方式，结点定义如下：

二叉树的层次遍历就是按照从上到下、每一层从左到右的顺序访问树种的全部结点。因某一层中先访问的结点其孩子结点在下一层也将先访问，因此可以借助一个环形队列 `qu` 来实现。
