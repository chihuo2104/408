## 二叉树的遍历

### 先序遍历非递归算法2

```
if 当前树不空 {
  p = b；
  while (栈不为空或p不等于NULL) {
    while (p不为空) {
      访问 p 所指节点，将p进栈
      p = p -> lchild;
    }
    if 栈不空 {
      出栈p;
      p = p -> rchild;
    }
  }
}

### 二叉树的层次遍历

从上至下 从左至右

实际上一个数组就可以做到了

过程：先将根节点进队，在队不空时循环：从队列中出列一个节点 *p 访问它，若它有左孩子节点，将左右孩子节点进队，如此操作直到队空。
