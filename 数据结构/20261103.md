## 第八章 图

### 8.2.1 邻接矩阵存储方法

可以理解为一个表矩阵，a[i][j]，如果是无向表，值为1时连接，值为0时不连接；如果为有向表 a[i][j] = 1 代表 i -> j 连通, 如果是带权图的话，那么这个值就变成了相应权值。

图的完整邻接矩阵类型定义如下：

```c
#define MAXV [max point numbers]
#define INF 32767

typedef struct {
    int no;
    InfoType info;
} VertexType;

typedef struct {
    int edges[MAXV][MAXV];
    int n, e;
    VertexType vexs[MAXV];
} MatGraph;
```

邻接矩阵的特点有：

1. 图的邻接矩阵的表示是唯一的
2. 对于含有 n 个顶点的图，当采用邻接矩阵存储时，无论是有向图还是无向图，无论边的数目是多少，存储空间都为 O(n^2)
3. 无向图的邻接矩阵数组一定是一个对称矩阵，因此可以进行上下三角压缩
4. 对于无向图，邻接矩阵数组的第 i 行或第 i 列非零元素，非正无穷元素的个数正好是顶点 i 的度
5. 对于有向图，可以把 4 改为正好是 i 的 入度 或 出度
6. 在邻接矩阵中，判断图中两个顶点之间是否有边或者求两个顶点之间的边的权的执行时间为 O(1)，所以在需要提取边框值的算法中通常采用邻接矩阵。

### 8.2.2 邻接表存储方法

可以理解为是 n 个以 n 节点开始的一个路径，也就是说把 i 所有的邻接点连接起来（意思就是 i 连接着的元素就以单链表的方式进行提供即可

图的完整邻接表存储类型的声明如下：

```c
typedef struct ANode {
    int adjvex;
    struct ANode *nextarc;
    int weight;
} ArcNode;

typedef struct Vnode {
    InfoType data;
    ArcNode *firstarc;
    
} VNode;

typedef struct {
    VNode adjlist[MAXV];
    int n, e;
} AdjGraph;
```

还可以设计一个逆邻接表（每个顶点链接的是指向该顶点的边）

邻接表的特征如下：

- 邻接表的表示不唯一，在每个顶点对应的单链表个边节点的排列顺序是可以不同的（取决于建立邻接表的算法以及边的输入次序）
- 对于 n 个节点，e 条边的无向图，其邻接表有 n 个头节点和 2e 个边节点。如果是有向图，则为 n 个头节点和 e 个边节点。稀疏图使用邻接表会更省空间。
- 对于无向图，邻接表中顶点 i 对应的第 i 个单链表的边节点数正好是顶点 i 的度，而对于有向图，邻接表中顶点 i 对应的第 i 个单链表的边节点数目仅是顶点 i 的出度，顶点 i 的入度为邻接表中所有 adjvex 域值为 i 的边节点数目
- 查找顶点 i 关联的所有边是非常快速的，因此提取某个顶点的所有邻接点算法中通常采用邻接表存储结构
