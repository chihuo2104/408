### 数据结构和数据类型

高级程序设计语言中，一般需要对程序中出现的每个变量、常量或表达式，明确说明它们所属的数据类型。不同类型的变量所可取的范围不同，所能进行操作不同。

数据类型：一个值的集合和定义在此集合上的一组操作的总称。

我们亦可通过自己的需要来创造一个新的数据类型（如 `struct`）

### 抽象数据类型

抽象数据类型(Abstract Data Type, ADT) 由一组数据结构和在数据结构上的一组操作所组成。

一般格式(自然语言+伪代码)：

```text
ADT 抽象数据名 {
  Data:
    数据描述
  Operations:
    操作声明(对运算功能的描述)
}ADT 抽象数据类型名
```

### for example

复数类型的定义

```text
ADT Complex {
  Data:
    D = {(e₁, e₂) | e₁, e₂ ∈ ℝ}
    R = {⟨e₁, e₂⟩ | e₁ 为实部，e₂ 为虚部}
  Operations:
    AssignComplex(&z, v1, v2): 构造复数Z
    DestroyComplex(&z): 销毁复数Z
    GetReal(z, &real): 获取实部
    GetImag(z, &imag): 获取虚部
    Add(...)
    ...
} ADT Complex
```

## 1.2 算法及其描述

### 什么是算法？

数据元素之间的关系有逻辑关系和物理关系，对应的操作有 **逻辑结构上的操作功能** 和 **具体结构上的操作实现** 。

通常把具体存储结构上的操作实现步骤或过程称为 **算法** 。

```text
逻辑结构上的操作功能 —— 算法设计 -> 合适的数据表现形式
                       ^
                       |-> 目的：为了更简单的解决问题
                       v
存储结构上的操作实现 —— 算法实现 -> 合适的实现方式
```

### 算法的五个重要特性

- 有穷性：在有穷步之后结束
- 确定性：无二义性
- 可行性：可经过基本运算有限次执行来实现
- 有输入
- 有输出

任何算法都必须遵守

### for example

```c
void exam1()
{ int n=2
    while (n%2==0)
        n=n+2;
    printf("%d\n", n);
}
```

此算法就是典型的违反了有穷性的示例，`while (n%2==0)` 是一个死循环。

```c
void exam2()
{   int x,y;
    y=0;
    x=5/y;
    printf("%d,%d",x,y);
}
```

此算法就是典型的违反了可行性的示例，不能除以 0.

### 算法设计的目标

- 正确性
- 可使用性
- 可读性
- 健壮性（鲁棒性），要求算法具有很好的容错性
- 高效率与低存储量需求，通常算法的效率是指算法的执行时间，算法存储量是指算法执行过程中的所需的最大存储空间。效率和低存储量这两者都与问题的规模有关。二者大概率是不可兼得的。通常情况下会牺牲存储量来换高效率。

### 算法时间复杂度分析

一个算法是由控制结构（顺序、分支和循环）和原操作构成的，则算法时间则是两者的效果

e.g.

```c
void fun(int a[], int b[]) {
    int i;
    for (i=0; i<n; i++) {
        a[i] = 2 * i; // 第一个 for 循环，执行 n 次
    }
    for (i=0; i<n; i++) {
        printf("%d ", a[i]); // 第二个，也是执行 n 次
    }
    printf("\n");
}
```

于是我们可以进行以下优化（虽然优化不大）：

```c
void fun(int a[], int b[]) {
    int i;
    for (i=0; i<n; i++) {
        a[i] = 2 * i; // 第一个 for 循环，执行 n 次
        printf("%d ", a[i]); // 把第二个输出塞到了第一个里面
    }
    printf("\n");
}
```

### 时间复杂度 O(n)

通常把算法中包含基本运算次数的多少称为算法的时间复杂度，也就是说一个算法的时间复杂度是指该算法的基本运算次数。

算法中基本运算被计为算法基本运算的一般是最深层循环内的语句, 我们只看影响最大的。

一般来说只需要求出 T(n) 的最高阶就可以了。

### 常用数量级/时间复杂度

没有循环算法，基本运算次数与问题规模无关，O(1)，常数阶。

一个只有一重循环的算法，基本运行次数是和问题规模呈现线性增长的，记作 O(n)，也称线性阶。

其余常用还有 平方阶 立方阶 对数阶 和 指数阶 等

为什么要进行时间复杂度的分析[^2]？

### 算法空间复杂度分析

空间复杂度是对一个算法在运行过程中临时占用的存储空间大小的量度，一般也作为问题规模 n 的函数，以数量及形式给出记作：

```
S(n) = O(g(n))
```
