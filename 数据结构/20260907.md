### 线性表的基本概念

线性表是具有 **相同特性的数据元素** 的一个 **有限** 序列。

该序列中 **所含元素的个数** 叫做线性表的长度，用 n 表示，n>=0。

当 n=0 时，表示该线性表无元素，为空表（要区分不存在的表！）

设序列中第 i （i 在这里表示逻辑位序）个元素 ai（1<=i<=n)

线性表的一般表示为：

```text
(a1,a2,......,ai,ai+1,......,an) <== 逻辑结构表示
```

对于 a1 来说，a1 没有前继，但是有后续，an 没有后续，但是有前继。

其中 a1 为第一个元素，称为表头元素；an 为 最后一个元素，称为表尾元素。

### 线性表的运算

线性表的基本运算如下：

- 初始化线性表：`InitList(&L)`: 构造一个空的线性表 L（分配空间的过程）
- 销毁线性表：`DestroyList(&L)`: 释放线性表 L 所占用的内存空间（释放空间的过程）

> `&` 符号 在这里起到什么作用？[^2]

[^2]: 引用

基本流程:

```text
InitList(&L) 初始化线性表 => ...... => DestroyList(&L) 销毁线性表
```

- 判断线性表是否为空表: `ListEmpty(&L)`，若 L 为空表，则返回真，否则返回假。
- 求线性表的长度: `ListLength(&L)`，返回 L 中的元素个数
- 输出线性表: `DispList(L)`，输出整个线性表的值
- 求线性表 L 中指定位置的某个数据元素: `GetElem(L,i,&e)`，用 e 返回 L 中 第 i 个元素的值
- 定位查找: `LocateElem(L,e)`，输出 L 的第 i 个元素的值
- 插入数据元素 `ListInsert(&L, i, e)`： 在 L 的第 i 个元素之前插入新的元素 e，L 的长度增 1
- 删除数据元素 `ListDelete(&L, i, &e)`: 删除 L 的第 i 个元素，并用 e 返回其值，L 的长度减 1

### 线性表的顺序存储结构

把线性表中的所有元素按照其逻辑顺序依次存储到从计算机存储器中指定存储位置开始的 **一块连续的存储空间** 中。

因此，线性表中的第一个元素的存储位置就是指定的存储位置，第 i+1 个元素的存储位置紧接在第 i 个元素的存储位置的后面。

> 线性表和顺序表有什么区别？[^3]

[^3]: 数据结构和逻辑结构的区别

e.g. 假设线性表的元素类型为 ElemType，则每个元素所占用存储大小（即字节数）为 sizeof(ElemType)，整个线性表所占用的存储空间大小为：

```c
n * sizeof(ElemType) // 其中，n 表示线性表的长度
```

可以根据一个首/中/后地址来计算出来存储的地址。

| 下标位置 | 线性表存储空间 | 存储地址    |
|---------|--------------|-----------|
|0|a1|LOC(A)|
|1|a2|LOC(A)+sizeof(ElemType)|
|...|...||
|i-1|ai|LOC(A)+(i-1)*sizeof(ElemType)|
|...|...||
|n-1|an|LOC(A)+(n-1)*sizeof(ElemType)|
|...|...||
|MaxSize-1|...|LOC(A)+(MaxSize-1)*sizeof(ElemType)|

*顺序表示意图

*一般，我们可以把 MaxSize 设置成 n 的 2 倍*

万一是插入新的数据呢？怎么办？

没有空间容纳新的数据！

理论上来说分配的内存空间应该是 大于等于 n * sizeof(ElemType) 的

线性表<==直接映射==>顺序表

各个元素，所有元素的信息都是存储于线性表当中的(加一个长度 n，可以方便获得线性表的当前长度，更加节省时间)

e.g. 城市地址信息

### 顺序表基本运算的实现

e.g. 使用 C/C++ 实现其基本运算

- 初始化顺序表 `InitList(L)`，时间复杂度为 `O(1)`

```c
void InitList() {
    L = (SqList *) malloc(sizeof(SqList));
    L -> Length = 0;
}
```

- 建立顺序表 `CreateList()`, 时间复杂度为 `O(n)`

```c
void CreateList(SqList *&L,ElemType a[], int length) {
    L -> length = length;
    for (i = 0; i < length; i++) {
        L -> data[i] = a[i];
    }
}
```

> 在 C++ 中，若函数参数为 `SqList *L`，函数内的修改是否会保留？[^4]

[^4]: 不会

不使用 `&` 引用符号的话，实参不会变化，变化的只会是实参。

- 销毁顺序表 `DestroyList(L)`, 时间复杂度为 `O(1)`

```c
void DestroyList(SqList *&L) {
    free(L);
}
```

- 判断是否为空表 `ListEmpty(L)`, 时间复杂度为 `O(1)`

```c
bool ListEmpty(SqList *L) {
    return (L-> length == 0); // 判断长度是否不为 0
}
```

- 输出线性表 `DispList(L)`,时间复杂度为 `O(n)`

该运算当线性表 L 不为空时，顺序显示 L 中个元素的值。

```c
void DispList(SqList *L)
{
    int i;
    if (ListEmpty(L)) return;
    for (i = 0; i < L -> length; i++) {
        printf("%c", L -> data[i])
    }
    printf("\n")
}
```

- 求某个数据元素值 `GetElem(L, i, e)`，时间复杂度为 `O(1)`（体现了顺序表的随机存取特性）

```c
bool GetElem(SqList *L, int i, ElemType &e) {
    if (i < 1 || i > L -> length) return false;
    e = L -> data[i-1];
    return true;
}
```

- 按元素值查找 `LocateElem(L, e)`，时间复杂度为 `O(n)`

```c
int LocateElem(SqList *L, ElemType e) {
    int i = 0;
    while (i < L -> length && L -> data[i] != e) i++;
    if (i>= L-> length) return 0;
    else return i+1;
}
```

- 插入数据元素 `ListInsert(L, i, e)`，时间复杂度为 `O(n)`

首先需要判断 i 位置是否合法，然后再进行后移（就是说把第 i 个位置腾出来给新元素来使用），然后最后该顺序表的长度加1，变为 n + 1

```c
bool ListInsert(SqList *&L, int i, ElemType e) {
    int j;

    // 边界处理
    if (i < 1 || i > L -> length + 1) return false;

    // 后移，然后把length += 1
    i--;
    for (j = L -> length; j > i; j--) {
        L -> data[j] = L -> data[j - 1];
    }
    L -> data[i] = e;
    L -> length++;
    return true;
}
```

- 删除数据元素 `ListDelete(L, i, e)`，时间复杂度为 `O(n)`

类似于插入，其实差不多是插入的相反处理手法。

```c
bool ListDelete(SqList *&L, int i, ElemType &e) {
    int j;

    // 边界处理
    if (i < 1 || i > L -> length + 1) return false;
   
    // 后移，然后把length += 1
    i--;
    e = L -> data[i];
    for (j = i; j < L -> length - 1; j++) {
        L -> data[j] = L -> data[j+1];
    }
    L -> length--;
    
    return true;
}
```
