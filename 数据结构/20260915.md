## 第二章 线性表

## e.g. 有一个带头节点的单链表 L（至少有一个数据节点），设计一个算法使其元素递增有序排列。

```c
void sort(LinkList *&L) {
    LinkList *p,*pre,*q;
    p = L -> next -> next;
    L -> next -> next = NULL;
    while (p != NULL) {
        q = p -> next;
        pre = L;
        while (pre -> next != NULL && pre -> next -> data < p -> data) pre = pre -> next;
        p -> next = pre -> next;
        pre -> next = p;
        p = q;
    }
}
```

## 双链表

单链表和双链表有什么不同？[^1]

[^1]: 双链表比单链表多了 prev 指向前面的元素

### 创建双链表

```c
void CreateListF(DLinkList *&L, ElemType a[], int n) {
    DLinkList *s;
    int i;
    L = (DLinkList *) malloc(sizeof(DLinkList));
    L -> prev = L -> next = NULL;
    for (i = 0; i < n;i++) {
        s = (DLinkList *) malloc(sizeof(DLinkList));
        s -> data = a[i];
        s -> next = L -> next;
        if (L -> next != NULL) L -> next -> prev = s;
        L -> next = s;
        s -> prev = L;
    }
}
```

### 单链表和双链表有什么区别？

双链表和单链表的最大区别就是加了一个 prev 的前指针，方便从后往前进行寻址。

### 中间插入

1. s -> next = p -> next
2. p -> next -> prev = s
3. p -> next = s
4. s -> prev = p

小问题：这四个顺序可以调换吗？ 其实是可以的。但是不能自由的切换。
比如说你可以先换 prev，再换 next。

## 循环链表

双链表尾节点的 next 连接着 头节点的 prev，就可以构建成一个循环链表了。 // OR 单链表尾节点指向头节点即可

循环链表是另一种形式的链式存储结构，它的特点是表中最后一个节点的指针域不再是空，而是指向表头节点，整个链表形成一个环。由此从表中的任意节点触发均可找到链表中的其他节点。
