## 第二章 线性表

### for example 

已知长度为 n 的线性表 A 采用顺序存储结构，编写一个时间复杂度为 O(n)，空间复杂度为 O(1) 的算法，该算法需要删除线性表中所有值为 x 的元素。

- 如果每次删除都进行移动，时间复杂度为 O(n^2)，空间复杂度为 O(1)
- 如果用一个新的顺序表来实现，其时间复杂度为 O(n)，空间复杂度为 O(n)

我的思路：可以先遍历一遍 x 值，把所有的 x 值清空，清空之后顺路往前移动，这样就可以做到时间复杂度 O(n)，空间复杂度 O(1) 了。

```c
int ListDeleteByVal(SqList *&L, int value, ElemType &e) {
    int k, count;
   
    for (i = 0; i < L -> length - 1; i++) {
        if (L -> data[i] != value) {
            L -> data[k] = L -> data[i];
            k++;
        }
        L->length = k;
    }
    
    return count;
}
```

时间和空间都做了一个限制，算法设计主要讨论的就是如何在有限的时间和空间当中实现这个功能。

解法2

```c
void delnode2(SqList *&L, ElemType x) {
    int k = 0, i = 0;

    while (i < L -> length) {
        if (L->data[i] == x) {
            k++;
        } else {
            L->data[i-k] = L->data[i];
        }
        i++;
    }
    L->length = k;
}
```

直接后移，不是扫描遍历。

## 线性表的链式存储

### 链表

在链式存储中，每个存储节点不仅包含有所存元素本身的信息（称之为数据域），而且包含有元素之间逻辑关系的信息，即前驱节点包含后继节点的地址信息，这称为指针域，这样可以通过前驱节点的指针域方便的找到后继节点的位置，提高数据查找速度。

一般的，每个节点有一个或多个这样的指针。

因为顺序表是一对一的逻辑关系，因此我们只需要一个前驱/后继指针域即可。

为了方便插入和删除运算，每个链表会带有一个头节点，并通过头节点的指针唯一标识该链表。

```text
L -> [a1] | next -> [a2] | next -> ...... -> [an] | next -> null
```

```
Pros: 对内存的要求较低
Cons：存储密度较低，不经济
```

顺序表的存储密度为 1，链表的存储密度一般是 <1，指针所占的空间与数据相同的话，密度则为 50%。

单链表中我们只能按照顺序访问后继节点，而无法访问它的前驱节点（除非你做的是双链表）

```text
L <-> prev | [a1] | next <-> prev | [a2] | next <-> ..... <-> tail
```

头节点可以是一个指针，也可以是一个数据，两种都是可用的，设计链表一般根据实际情况来进行确认。

LinkList 类型的定义如下：

```c
typedef struct LinkList {
    LinkList *next;
    int data;
}
```

操作：

> 为什么不先讲初始化？因为其实没什么必要，通过指针把节点连接起来，可以把它看成从一个空的单链表出发，一次一次的从空表中插入新节点，插入多个新节点来生成这个单链表，需要逐节点进行遍历。

- 插入操作

```c
s -> next = p -> next;
p -> next = s;
```

特点：只需要修改相关节点的指针域，不需要移动节点。

修改2个指针，即可完成插入操作。

- 删除操作

```c
q = p -> next;
p -> next = q -> next; // or p -> next -> next
free(q); // 回收空间
```

特点：只需要修改相关节点的指针域，不需要移动节点。

和顺序表有什么区别？插入/删除明显是链表比顺序表更快。

- 初始化线性表 `InitList(L)`

```c
void InitList(LinkList *&L) {
    L = (LinkList *) malloc(sizeof(LinkList)); // 创建头节点
    L->next = NULL;
}
```

或

```c
void InitList(LinkList *&L) {
    L->next = NULL;
}
```

- 建立单链表

1) 头插法 新节点在表头
2) 尾插法 新节点在表尾

进行不停插入新节点的过程。

头插法代码实现

```c
void CreateListF(LinkList *&L, ElemType a[], int n) {
    LinkList *s;
    int i;
    L = (LinkList *) malloc(sizeof(LinkList));
    L -> next = NULL;
    for (i=0;i<n;i++) {
        s = (LinkList *) malloc(sizeof(LinkList));
        s -> data = a[i];
        s -> next = L -> next;
        L -> next = s;
    }
}
```

尾插法代码实现

```c
void CreateListR(LinkList *&L, ElemType a[], int n) {
    LinkList *s, *r;
    int i;
    L = (LinkList *)malloc(sizeof(LinkList));
    for (i = 0; i < n; i++) {
        s -> data = a[i];
        r -> next = s;
        r = s;
    }
    r -> next = NULL;
}
```

- 求线性表的长度

```c
int ListLength (LinkList *L) {
    int n = 0;
    LinkList *p = L;
    while (p -> next != NULL) {
        n++;
        p = p -> next;
    }
    return n;
}
```
