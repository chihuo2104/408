## 第二章 线性表

- 输出线性表

```c
void DispList(LinkList *L) {
    LinkList *p = L -> next;
    while (p != NULL) {
        printf("%d ", p -> data);
        p = p -> next;
    }
    printf("\n");
}
```

- 按照索引获取一个元素

```c
bool GetElem(LinkList *L, int i, ElemType &e) {
    int j = 0;
    LinkList *p = L;
    while (j < i && p != NULL) {
        j++;
        p=p->next;
    }
    if (p == NULL) return false;
    else {
        e = p -> data;
        return true;
    }
}
```

链表因为不是连续进行存储的内容，所以必须得经过一次遍历才能获取到正确的值，因此它的获取值的时间复杂度为 `O(n)`

- 插入数据元素

```c
bool ListInsert(LinkList *&L, int i, ElemType e) {
    int j = 0;
    LinkList *p = L, *s;
    while (j < i - 1 && p != NULL) {
        j++;
        p = p -> next;
    }
    if (p == NULL)
      return false;
    else {
        s = (LinkList *) malloc(sizeof(LinkList)); 
        s -> data = e;
        s -> next = p -> next;
        p -> next = s;
        return true
    }
}
```

实际上就是找到这个新节点之前的next指针，修改一下插入数据和修改数据的指针即可，不需要进行前后移动的操作了。

那能不能综合数组和链表的优势，构造出一个数组，对应指向数据的指针呢？笔者查了下还真有，这玩意叫间接寻址，用了 70 年了，页表，数据库索引都在用这个。

- 删除数据元素

```c
bool ListDelete(LinkList *&L, int i, ElemType &e) {
    int j = 0;
    LinkList *p = L, *q;
    while (j < i - 1 && p != NULL) {
        j++;
        p = p -> next;
    }
    if (p == NULL) return false;
    else {
        q = p -> next;
        if (q == NULL) return false;
        e = q -> data;
        p -> next = q -> next;
        free(q);
        return true;
    }
}
```

## e.g.

有一个带头节点的单链表 L，设计一个算法将其拆分成两个带头节点的单链表 L1 和 L2（其中 L1 是奇数项集，L2 为偶数项集），要求 L1 使用 L 的头节点

### 笔者思路

while循环，if判断 i % 2 == 0 加入 L1，反之加入 L2，或者是可以再进行优化，i % 2 == 1 时候直接把节点拆分出 L，另外开一个 L2 链表，这样的话就不需要另外开一个 L1 表进行操作了。
