## 图的深度优先遍历

### 任务描述

### 数据组织

## 解题思路

深度优先遍历的过程是从图中某个初始点 `v` 出发，首先访问初始点 `v` ，然后选择一个与顶点 `v` 相邻且没被访问过的顶点 `w` ，以 `w` 为初始顶点，再从它出发进行深度优先遍历，直到图中与顶点v邻接的所有顶点都被访问过为止，该过程是一个递归过程。
函数声明

```c

```

### 解题思路

广度优先遍历的过程是首先访问初始点v，接着访问顶点v的所有未被访问过的邻接点v1，v2，...vt，然后按照v1，v2，...vt的次序访问每一个顶点的所有未被访问过的邻接点，以此类推，直到图中所有和初始点v有路径想通的顶点都被访问过为止。

以邻接表为存储结构，在广度优先遍历图时需要使用到队列帮助完成图的遍历。

```c

//图的基本运算算法
#include <stdio.h>
#include <malloc.h>
#include "graph.h"

//------------------------------------------------------------
//----邻接表的基本运算算法------------------------------------
//------------------------------------------------------------

void CreateAdj(AdjGraph *&G, int A[MAXV][MAXV], int n, int e)
//创建图的邻接表
{
    int i, j;
    ArcNode *p;

    G = (AdjGraph *)malloc(sizeof(AdjGraph));

    //给邻接表中所有头结点的指针域置初值
    for (i = 0; i < n; i++)
        G->adjlist[i].firstarc = NULL;

    /**********begin*************/
    //遍历数组A，查找合适元素（值不为0，不为无穷大），创建边结点，采用头插法插入链表
    for (i = 0; i < n; i++)
    {
        // 逆序遍历，配合头插法，使邻接点按编号从小到大输出
        for (j = n - 1; j >= 0; j--)
        {
            if (A[i][j] != 0 && A[i][j] != INF)
            {
                p = (ArcNode *)malloc(sizeof(ArcNode));
                p->adjvex = j;
                p->weight = A[i][j];
                p->nextarc = G->adjlist[i].firstarc;
                G->adjlist[i].firstarc = p;
            }
        }
    }
    /**********end*************/

    G->n = n;
    G->e = e;
}

//输出邻接表G
{
    int i;
    ArcNode *p;

    for (i = 0; i < G->n; i++)
    {
        p = G->adjlist[i].firstarc;
        printf("%3d: ", i);
        while (p != NULL)
        {
            printf("%3d[%d]→", p->adjvex, p->weight);
            p = p->nextarc;
        }
        printf("∧\n");
    }
}

void DestroyAdj(AdjGraph *&G)
//销毁图的邻接表
{
    int i;
    ArcNode *p, *q;

    for (i = 0; i < G->n; i++)
    {
        p = G->adjlist[i].firstarc;
        while (p != NULL)
        {
            q = p->nextarc;
            free(p);
            p = q;
        }
    }
```

```c
#include <stdio.h>

void MatToList(MatGraph g, AdjGraph *&G)
//将邻接矩阵g转换成邻接表G
{
    int i, j;
    ArcNode *p;

    G = (AdjGraph *)malloc(sizeof(AdjGraph));

    // 初始化邻接表所有头结点的指针域
    for (i = 0; i < g.n; i++)
        G->adjlist[i].firstarc = NULL;

    // 遍历邻接矩阵，建立边结点
    for (i = 0; i < g.n; i++)
    {
        // 逆序遍历 j，配合头插法，使链表中邻接点按编号从小到大排列
        for (j = g.n - 1; j >= 0; j--)

                p->nextarc = G->adjlist[i].firstarc;
                G->adjlist[i].firstarc = p;
            }
        }
    }
```

### 解题思路

```c
#include "graph.cpp"

void ListToMat(AdjGraph *G, MatGraph &g)
//将邻接表G转换成邻接矩阵g
{
    int i, j;
    ArcNode *p;

    g.n = G->n;
    g.e = G->e;

    // 初始化邻接矩阵：主对角线为0，其他元素为INF
    for (i = 0; i < g.n; i++)
    {
        for (j = 0; j < g.n; j++)
        {
            if (i == j)
                g.edges[i][j] = 0;
            else
                g.edges[i][j] = INF;
        }
    }

    // 遍历邻接表的每个单链表，填充邻接矩阵
    for (i = 0; i < G->n; i++)
    {
        p = G->adjlist[i].firstarc;
        while (p != NULL)
        {
            g.edges[i][p->adjvex] = p->weight;
            p = p->nextarc;
        }
    }
}
```
