## 第七章 树和二叉树

## 哈夫曼树

给定 n 个权值 {w1,w2,....,Wn}，F 为一个树林

在 F 中 选取更节点的权值最小的和次小的两棵二叉树作为左右子树构造一棵新的二叉树

在集合中删去两棵二叉树，将新二叉树加入 F 中，以此类推，最后剩下的二叉树即为哈夫曼树

### e.g. W = { 5, 29, 7, 8, 14, 23, 11 }

选择 3 5 => 8; 7 8 => 15; 11 8 => 19; 14 15 => 29; 19 23 => 42; 29 29 => 58

哈夫曼树：

  100
  / \
42  58
19 23 29 29
/         \
8 11     14 15
/            \
3 5        7 8

哈夫曼树没有单分支节点。

叶子 n ， 双分支： n - 1

哈夫曼树的数据结构定义

```c
typedef struct {
    char data; // 节点值
    float weight; // 权重
    int parent; // 双亲节点
    int lchild; // 左孩子节点
    int rchild; // 右孩子节点
} HTNode;
```

使用了数组类型进行定义

一共有 2n - 1 节点

算法思路

parent / lchild / rchild 设置为 -1

一个一个进行处理，选择两个最小的，weight相加即可
